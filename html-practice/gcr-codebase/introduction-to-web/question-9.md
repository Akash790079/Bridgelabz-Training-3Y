# Question 9

**Q: Research and list five web browsers. Explain how rendering engines differ between them.**

### Answer:

**Five Popular Browsers and Rendering Engines:**
1. **Google Chrome** - Engine: **Blink**
2. **Mozilla Firefox** - Engine: **Gecko**
3. **Apple Safari** - Engine: **WebKit**
4. **Microsoft Edge** - Engine: **Blink**
5. **Brave** - Engine: **Blink**

**Difference in Rendering Engines:**
A rendering engine turns HTML, CSS, and JavaScript code into visible pixels on screen.
- **Blink & WebKit:** Focus on fast speed and high performance.
- **Gecko:** Developed by Mozilla, focuses on privacy and custom web standards.
Different engines parse CSS styles and calculate page layouts slightly differently.
