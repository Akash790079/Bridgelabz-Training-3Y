# Question 8

**Q: Explain the difference between static and dynamic websites. Provide an example of each.**

### Answer:

1. **Static Website:**
   - Content is fixed in HTML files and stays the same for all users.
   - Does not require a database.
   - Loads quickly and easy to host.
   - **Example:** A simple company portfolio page or small business menu page.

2. **Dynamic Website:**
   - Content changes based on user interactions, login, or database data.
   - Requires a database and backend server.
   - **Example:** YouTube, Facebook, or Amazon where every user sees different content.
