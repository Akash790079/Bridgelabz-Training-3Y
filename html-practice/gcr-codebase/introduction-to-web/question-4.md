# Question 4

**Q: Identify and list the tools required to set up a web development environment. Explain the purpose of each.**

### Answer:

Here are the main tools needed for web development:

1. **VS Code (Code Editor):**
   - **Purpose:** Used to write and edit HTML, CSS, and JavaScript code.

2. **Web Browser (Google Chrome / Firefox):**
   - **Purpose:** Used to view and test web pages, and debug code using Developer Tools.

3. **Git & GitHub:**
   - **Purpose:** Used for version control, saving code history, and uploading projects online.

4. **Node.js & npm:**
   - **Purpose:** Used to run JavaScript outside the browser and install project packages.

5. **Terminal / Command Prompt:**
   - **Purpose:** Used to run developer commands, git commands, and local servers.
