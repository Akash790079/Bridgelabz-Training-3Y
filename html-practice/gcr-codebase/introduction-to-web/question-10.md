# Question 10

**Q: Explain the basic web architecture flow — client, server, database, and APIs.**

### Answer:

**Web Architecture Flow:**

1. **Client (Browser):** User fills a form or clicks a button on the website.
2. **API Request:** The browser sends an HTTP request payload to the server.
3. **Server Logic:** The server receives the request, verifies user credentials, and processes logic.
4. **Database Query:** The server fetches or saves data in the Database (like SQL or MongoDB).
5. **Response:** The server returns data back as JSON/HTML to the Client to show on screen.
