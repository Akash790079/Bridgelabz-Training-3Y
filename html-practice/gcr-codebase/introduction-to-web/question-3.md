# Question 3

**Q: Describe how a browser requests and displays a web page from a web server.**

### Answer:

When we type a website link in a browser, it follows these simple steps:

1. **DNS Lookup:** The browser converts the website name (like `google.com`) into an IP address.
2. **Connection:** The browser connects securely with the web server.
3. **HTTP Request:** The browser sends a request to the server for the page files.
4. **Server Response:** The server sends back the HTML, CSS, and JS files.
5. **HTML & CSS Parsing:** The browser reads HTML to build the page structure (DOM) and CSS for styles (CSSOM).
6. **Displaying Page:** The browser combines the structure and style to draw (paint) the final page on screen.
