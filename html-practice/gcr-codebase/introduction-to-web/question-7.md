# Question 7

**Q: Install VS Code and configure it for HTML, CSS, and JavaScript development.**

### Answer:

**Steps to Install and Setup VS Code:**

1. Download VS Code from `code.visualstudio.com` and install it.
2. Open VS Code and click **File > Open Folder** to open a project directory.
3. Create three basic files:
   - `index.html` (for page structure)
   - `style.css` (for design)
   - `script.js` (for logic)
4. **Install Extensions:**
   - **Live Server:** To preview pages in real-time.
   - **Prettier:** To format code automatically.

**Folder Setup:**
- `my-project/`
  - `index.html`
  - `style.css`
  - `script.js`
