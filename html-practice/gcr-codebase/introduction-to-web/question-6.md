# Question 6

**Q: Define the roles of a frontend developer, backend developer, and database administrator in a project.**

### Answer:

1. **Frontend Developer:**
   - Builds the visual design and user interface of a website.
   - Makes web pages responsive and interactive using HTML, CSS, and JavaScript.

2. **Backend Developer:**
   - Builds server-side logic and API endpoints.
   - Handles user login, security, payment handling, and database communication.

3. **Database Administrator (DBA):**
   - Manages and organizes all project databases.
   - Handles data security, table design, backup creation, and query speed optimization.
