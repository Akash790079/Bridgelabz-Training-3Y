# Question 2

**Q: Explain how the client-server model works in web architecture.**

### Answer:

The client-server model works in two simple steps:

1. **Client (Request):**
   - The user opens a web browser (Client) and types a website address.
   - The browser sends an HTTP Request over the internet asking for page data.

2. **Server (Response):**
   - The Web Server receives the request, processes it, and finds the requested files.
   - The server sends back an HTTP Response containing HTML, CSS, and JavaScript files to the client.

**Simple Summary:**  
Client asks for data -> Server processes request -> Server sends data back to Client.
