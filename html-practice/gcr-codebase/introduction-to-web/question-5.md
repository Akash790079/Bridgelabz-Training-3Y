# Question 5

**Q: Explain what a web server is and give examples of commonly used servers.**

### Answer:

**What is a Web Server?**  
A web server is a system (computer software and hardware) that stores website files like HTML, CSS, images, and JavaScript, and delivers them to users over the Internet via HTTP/HTTPS protocols.

**Examples of Commonly Used Web Servers:**
1. **Apache HTTP Server** (Very common open-source web server)
2. **Nginx** (High-speed web server used for heavy traffic)
3. **Microsoft IIS** (Web server for Windows systems)
4. **LiteSpeed** (Fast commercial web server)
5. **Caddy** (Modern server with easy HTTPS setup)
