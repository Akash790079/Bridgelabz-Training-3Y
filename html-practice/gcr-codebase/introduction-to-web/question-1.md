# Question 1

**Q: Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.**

### Answer:

1. **Frontend Development:**
   - It is the client-side of a website that users see and interact with directly in their browser.
   - It includes buttons, layouts, images, and text styling.
   - **Technologies:** HTML, CSS, JavaScript.
   - **Example:** On Amazon, the search bar, product cards, and Add to Cart buttons are frontend parts.

2. **Backend Development:**
   - It is the server-side of a website that handles business logic, databases, and server operations behind the scenes.
   - **Technologies:** Node.js, Python, Java, MySQL.
   - **Example:** When you place an order on Amazon, checking stock in the database and processing payment is backend work.

3. **Full-Stack Development:**
   - It refers to working on both frontend (UI) and backend (server & database) together.
   - **Example:** Building a full e-commerce website from scratch by creating the UI screens as well as setting up the database.
